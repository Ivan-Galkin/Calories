# Agent Prompt Index

This directory is a lightweight index for project agents. The source-of-truth role prompts live in `docs/agents/`:

- Project Manager: `docs/agents/PROJECT_MANAGER.md`
- Designer: `docs/agents/DESIGNER.md`
- Developer: `docs/agents/DEVELOPER.md`
- QA Tester: `docs/agents/QA_TESTER.md`

When starting a new AI-assisted task, copy the relevant role prompt into the assistant/system context together with the current task and links to the product docs.
